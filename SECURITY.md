# Reporting issues

Report a rule false positive, missed artifact, or excessive scan cost through
GitHub Issues with the rule identifier, engine version, and a minimal inert text
reproducer. Never attach live malware, personal credentials, or private data.

This library does not execute files and does not provide an antivirus verdict.
Rules and data are experimental. Engine vulnerabilities belong with the
upstream YARA or YARA-X maintainers; do not publish an exploit here.
